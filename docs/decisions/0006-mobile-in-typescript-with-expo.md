# 0006. Mobile apps default to TypeScript with React Native and Expo

- Status: Superseded by [0007](0007-mobile-is-native-and-platform-guidelines-are-mandatory.md) the same day, before any project used it
- Date: 2026-11-14

## Context

The stack policy named Rust for native and embedded and TypeScript for web. The first real
project is a mobile app with a website, which neither rule covered. The owner was asked and had
not yet answered, so a default was assumed.

## Decision

React Native and Expo, to share TypeScript with the website.

## Consequences

The owner rejected this assumption. See 0007.
